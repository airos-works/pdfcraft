# ArtCraft brand marks

The ArtCraft name, wordmark and logos that upstream PdfCraft keeps in this directory are not in
this fork, as [`LICENSE-brand.txt`](LICENSE-brand.txt) requires of a published modified version:
PdfCraft for air/OS ships in air/OS images, so it must not carry the ArtCraft Marks or present
itself as an ArtCraft product. The app shows plain text where upstream draws the marks, and this
repository credits upstream in plain text only: PdfCraft for air/OS is based on
[PdfCraft](https://github.com/storytold/pdfcraft) by the ArtCraft team. `LICENSE-brand.txt` is
kept unchanged as the record of those terms.
